# easy-admin-by-prantho

> A 100% Framework-Agnostic Pure HTML & Tailwind CSS Admin Dashboard Skill for AI Agents (Vuexy, Materialize, and Fuse React aesthetics).

Designed for AI Coding Agents (Antigravity, Cursor, Claude Code, GitHub Copilot) and human developers.

---

## ⚡ Quick Install via [skills.sh](https://skills.sh)

Install this skill into any project with a single command:

```bash
npx skills add Prantho-das/easy-admin-by-prantho
```

---

## 🎯 Key Features

1. **Pixel-Perfect 1:1 Aesthetics**:
   - **Vuexy Admin**: Exact 260px sidebar, 62px floating navbar, Public Sans typography, signature gradient pills.
   - **Materialize Admin**: Material Design 3 (M3) elevation shadows, 10px card radius, right-rounded menu pills.
   - **Fuse React Admin**: Slate `#0F172A` theme, carded shelf header, 16px radius containers.
2. **Top Horizontal Child Navigation Tabs**:
   - Submenus automatically render as sleek horizontal tabs directly above the page content area.
3. **100% Pure HTML + Tailwind CSS**:
   - Zero framework lock-in. Works directly in Vanilla HTML, Laravel Blade, Vue, React, Next.js, Nuxt, Django, or Asp.Net.
4. **Multi-Theme Engine**:
   - Centralized CSS variable engine with support for instant theme switching and custom themes.
